# ADR 0009 · 世界观词汇承担状态，承诺永远用朴素词

## 背景

「同意凭证」「记忆切面」「成局证明」是代码的语言，不能上界面——这条没有争议。
有争议的是「种子」「发芽了」「开花了」「你的森林」算不算同一类东西。

它们看起来同样是"我们自己造的词"。

## 决定

**分两类，判据是「用户凭常识理解得了吗」。**

| | 领域词汇 | 世界观词汇 |
|---|---|---|
| 例 | 意图信号、成局证明、记忆切面、撮合窗口 | 种子、发芽了、开花了、森林 |
| 判据 | 要读文档才懂 | 凭常识就懂 |
| 上不上界面 | **不上** | **上** |

「你说的这句话就是那颗种子」——一个没读过任何文档的人看到这句话，
理解不会出错。「你的意图信号已进入撮合窗口」不行。

### 但世界观词汇只承担**状态**，不承担**承诺**

这是这条 ADR 真正管住的东西。

一件事长到哪一步了，用「发芽了」「结了花苞」「开花了」说
（`domain/model/growth.py` 的 `WORDS`）。

而**任何一个按下去就产生承诺的动作，用朴素词**：
「我加入」「就这么办」「我这边做完了」——不是「一起种」「浇个水」。

理由：世界观词汇是模糊的，而模糊在进度那一栏是优点、在承诺那一栏是缺陷。
「一起种」按下去之后我承诺了什么？没人说得清。不变量 11 说
**AI 可以代为表达，但不能代为承诺**——一个用户自己都说不清自己承诺了什么的
按钮，比 AI 代为承诺更糟。

### 每一档都要说得出判据

`WHY` 和 `WORDS` 一一对应：「发芽了」旁边写着「人齐了，还没开始定事情」。

说不出判据的进度条会被当成系统在评价你。而这件事由**可查的事实**定档
（不变量 6：共域因真实行动证据生长，不因聊天量生长）——聊了两百条而
一件事都没定，它就停在「发芽了」。**这不是惩罚，是诚实。**

### 旁边永远不出现数字

不给百分比，不给分数，不给排名。

一个百分比会立刻引出"凭什么是 40%"，而这件事本来就不精确到百分点：
定了时间没定地点，和定了地点没定时间，谁更"完成"？
生命周期的模糊性在这里是优点。

数字一旦出现，「这件事长到哪了」就会被读成「这个人做得怎么样」。

## 后果

- `check_vocabulary.py` 扫的是领域词汇表（从 `CONTEXT.md` 抓），
  世界观词汇不在表里，所以它不会误报
- 界面上同一件事有两套说法：状态那一栏说「开花了」，
  按钮那一栏说「我这边做完了」。**这是有意的**
- 新增一个世界观词之前先问：用户凭常识懂吗？懂就上，不懂就查映射表
