## 0. 结论先行

赛题最权威的一句话来自出题人本人（说话人2，00:34:33）：

> "在当今 AI 时代，如何帮助大学生实现'我想找到一个人'、'我想认识一个人'或'我想与一群人建立长期持久的社交关系'的愿望，**并最终真正一起完成一些事情**。"

这句话的重音在最后半句。整场分享会的两位讲者，用两套完全不同的语言，反复指向同一个判定标准：

**AI 在社交产品里的价值，不由 AI 产生了多少对话或内容来衡量，而由"有多少真人之间真实地多走了一步"来衡量。**

尤米的收尾原话（00:23:16）把这条标准压成一句：

> "AI 的价值不是替人去完成社交，而是能不能少替人说一句，但多帮两个人或两个群体向彼此更走近一步。"

因此本赛题真正的难点不是"做一个 AI 社交功能"，而是**在 48 小时内证明你的 AI 制造的是真实关系增量，而不是热闹**。

## 1. 赛题的三层结构

官方赛题描述本身"较为宏大"（说话人2 原话，00:33:18），需要拆成三层来读：

| 层级 | 内容 | 来源 |
|---|---|---|
| 表层命题 | AI 时代的校园社交连接器（宏大、不可直接施工） | 说话人2 承认其宏大 |
| 中层切口 | 三个更细的切入点：社交介质 / 需求找人 / 持续社群 | 说话人2 明确给出 |
| 底层判据 | 尤米的四个必答问题 + 说话人2 的"拿掉 AI 是否还成立" | 两位讲者分别给出 |

**关键理解**：底层判据是评分主轴，中层切口只是允许你把范围缩小的许可。选哪个切口不决定分数，能否通过底层判据才决定分数。

## 3. 官方明确的边界

### 3.1 明确要做

- 借助 AI，让大学生**理解或认识彼此**（说话人2，00:26:21）
- 想做事时**真的找到合适的人**（同上）
- 发生**线下或更深度**的社交关系（同上）
- 从校园里**真实的连接断点**切入（尤米，00:22:46）

### 3.2 明确不做（原话点名）

| 禁区 | 原话出处 |
|---|---|
| 校园通讯录 | 说话人2，00:26:21 |
| 校园墙（发布很多消息） | 说话人2，00:26:21 |
| 简单的聊天机器人 | 说话人2，00:26:21 |
| 在聊天列表里再加一个机器人 | 尤米，00:06:46 |
| 让 AI 替人完成最重要的确认或投入 | 尤米，00:09:45 |

### 3.3 明确不要求（现场问答确认）

- **不需要与抖音强关联**。原话问答（00:39:34–00:39:46）：
  > 问："咱们这个是需要和抖音做强关联的是吧？" 答："啊，不需要。"
  > 追问："就是不需要一定要跟小火人有关" 答："对，就是你们从自己观察到的校园里可能有什么样的场景，你们就按照自己想去做的那个东西，然后去 demo 就可以了。"
- **不需要完整前后端真实 APP**。尤米（00:37:23）："我自己的判断其实是不需要的，因为在 48 小时内，我觉得他也做不到。"
- **不需要真实用户量来自证有效**。尤米（00:37:49）："我觉得他也做不出来一个带后端、带前端，甚至像你刚刚说的带几千个用户和真实数据的体验，这肯定是做不到的。"

## 4. 交付物与验收

现场问答（00:35:28–00:38:02）把交付形态问清楚了，这是硬约束：

1. **方案 + 可体验的演示产品**，两者都要。说话人2（00:35:54）："不仅要有方案的部分，还应有一个可供体验的演示产品。"
2. **必须能被现场体验**。原因是**赛后有游园会活动**，"届时需要让大家体验"。
3. Demo 需要展示三件事：**产品大概的样子 / 解决什么问题 / AI 在其中发挥了什么作用**（说话人2，00:35:54）。
4. **有效性靠论证而非数据**。尤米（00:36:49–00:37:49）给的论证方法是：
   - 先假设你服务的是**哪一类用户群体**、他们处在**何种关系节点**；
   - 再用**数据和推送逻辑**论证其能辐射的**场景或用户规模足够大**；
   - Demo 处于"评委可以体验"的状态即可。
5. 时间盒：**48 小时**。

**推断**（非原话）：既然验收在"评委可体验"+"游园会真人体验"，那么交互完成度与叙事清晰度的权重，高于工程完备度。后端可以是假的，体验路径不能是断的。

## 5. 三个官方切入点（逐条拆解）

### 切入点 A：社交介质 —— 新时代的校园社交名片

说话人2 给了一条完整的**介质演化史**（00:27:03–00:28:17）：

```
姓名/学校/专业（传统名片）
  → 照片 / 兴趣 / 内容
  → 测评与共用身份标签（MBTI 类）
  → "我做过什么 + 我背后如何思考"（Second Me 类）
  → "我具备什么能力"（skill 形式）
  → ？  ← 赛题问的就是这个问号
```

他的原问：
- 在这个时代，我们应该怎么样来代表一个人？
- 新时代的校园社交名片、或者说这种新的介质，到底是什么样的东西？
- AI 在里面发挥什么样的作用？
- "关于互相交换的意愿，中间的媒介到底是什么？"（00:34:01）

**注意最后一问**：他问的不只是"名片长什么样"，而是"**交换意愿的媒介**是什么"。这把问题从展示层推到了交易层。

### 切入点 B：需求如何找到人

这是三个切口里描述最详细、断点最具体的一个。

**校园的天然禀赋**（00:29:18）：半封闭社会，天然共同身份（同校 / 同校区 / 同年级），天然存在的年级性需求。

**被点名的高频需求**（00:29:18）：搭档、选课、跨专业、能力交换、比赛、实践项目、组队。

**现有解法与其失效方式**（00:29:18–00:30:01）：
- 发校园墙、朋友圈问人、找熟悉的人、社团介绍、抖音发帖找队友、小红书发帖找队友
- 失效原因原话："这种效率其实可能并没有那么好，**可能刷到就刷到了，然后也就没了**。"

**四个被明确点名的断点**（00:30:01，极重要）：
1. 需求描述不清 —— "我到底应该找一个什么样的人？我想找什么样的人？"
2. 信任缺失 —— "有些陌生人还觉得你可能是个骗子"
3. 联系路径不明 —— "他不知道怎么去进一步地联系你"
4. 成局后无编排 —— "联系完了之后，下一步怎么安排呢？"

**他的思考题**（00:30:36–00:31:06）：
- 校园里最高频出现的社交/连接需求到底是什么？
- 通过已有工具或渠道，需求是否已被很好地满足？
- 如何让更多人看到这一需求？从哪些维度分发以提升效率与精准度？
- 如何判断两个人是匹配的？

### 切入点 C：持续共同体

比单次连接更深（00:31:06–00:32:11）：
- 如何推动产生更多共同记忆？
- 一次合作之后，能否促成下一次基于此的合作？
- 人越来越多，能否形成类似社群的团体组织？
- 线上关系是否会产生线下更深入的社交关系？
- 哪些需求可能发展成持续社群？AI 如何促成一次两次乃至多次活动？关系如何被**持续记录**？

## 6. 官方评审框架（四套，必须全部对上）

### 6.1 尤米的四个必答问题（00:21:47–00:22:46）—— 评分主轴

| # | 问题 | 备选答案（原话给的） |
|---|---|---|
| 1 | 你服务于**哪一段关系**？ | 陌生人 / 正在靠近的同伴 / 已建立关系的好友 |
| 2 | AI 介入**哪一个时刻**？ | 让人被看见 / 降低开口压力 / 促成共同行动 / 在已有对话中适时参与或延续 |
| 3 | 你把**什么权利留给了人**？ | 谁被连接、如何表述、是否回应、留下哪些记忆 |
| 4 | 结束后留下什么**关系资产**？ | ✗ 匹配记录、聊天记录（原话："我们认为这是没有价值的"）<br>✓ 共同的角色、共同的作品、共同的记忆、下一次互动的理由 |

### 6.2 说话人2 的必答题（00:33:18）

> "如果拿掉 AI，这个产品是否还能成立？AI 究竟在其中发挥了什么作用？或是减少了社交产品的哪一步，又或是促成了更深度社交关系的一些链接。"

注意他给的两种合格答法：**减少了哪一步** 或 **促成了哪种更深的链接**。这两者都是"减法/增量"表述，而不是"我们用了 LLM"。

### 6.3 关系五段链路（尤米，00:05:14 / 00:08:18）

```
被看见 → 找到开口的理由（低压力回应） → 共同行动 → 投入 → 共同记忆
```

原话判断（00:05:14）：**"市面上很多社交产品聚焦的只是第一步，最多完成第二步。真正困难的是如何让一次兴趣的信号最终变成一个群体的共同动作，并让这个动作成为你们下一次互动的理由。"**

对校园的额外要求（00:09:21）：**"在校园场景中，建议再往前多看一步，即行动。找到一个同好只是开始……如何组建队伍、办成一次活动、完成一个作品，或是让一个兴趣持续发展成一个活跃的社群。"**

### 6.4 社交场景中 AI 的三种能力（尤米，00:07:16）

前提：**社交产品的基本单位不是"用户"，而是"一段关系 / 一个小群体 / 一群人共同创造或经历的内容"。**

| 能力 | 工具型 AI 的做法（不够） | 社交型 AI 应做到 |
|---|---|---|
| 理解 | 理解个人兴趣标签 | 理解两人共同经历、互动节奏、**不该跨越的边界** |
| 生成 | 一句文本回复 | 表达素材、共同画像/形象、话题故事、**双方可共同参与的内容** |
| 行动 | 在对话中回复 | 推动轻量协作、共同决策、活动组织、**持续经营关系** |

### 6.5 两条产品路径（尤米，00:08:18）

| | 路径 A：陌生人连接 | 路径 B：已有关系 |
|---|---|---|
| AI 的任务 | 关系尚未开始时，帮双方被准确理解、找到自然话题 | 已认识甚至很熟，帮助继续互动、投入、留下共同记忆 |
| 隐喻（原话） | 降低第一次"敲门"的压力 | 在一个已有人居住的"屋子"里，呈现共同生活的痕迹 |
| 最终连接 | **必须由真人参与和确认** | — |

尤米明确："这两个路径都用了 AI，但其**问题或解法完全不同**。"

**路径 A 的三层帮助**（00:10:43）：
1. 抽象画像：把兴趣、人设、表达方式、当下需求抽象成 AI 和对方都能理解的东西
2. Agent 预热：agent-to-agent 或 user-to-agent，降低比较线索的门槛
3. Human in the loop：是否回应、是否交换联系方式、是否见面，**都应回归真人本身**

## 7. 送命清单：会被直接判为无价值的做法

这些都是原话点名，不是推断。

1. **AI 越聊越熟，真人见面只剩"嗯嗯哈哈"**（00:09:45）
   > "不要让两个 agent 或人与 AI 越聊越熟，导致真人见面时只剩下'嗯嗯，哈哈，你的 AI 挺不错的'这类对话。"
2. **虚假繁荣**（00:14:39）
   > "后台的 AI 对话量非常高，然而现实中大家并未发生真实的连接，只是躺在了彼此的聊天列表里。"
3. **用 AI 侧指标自证成功**（00:14:14）
   > "成功标准不应停留在 agent 聊了多少轮、生成了多少次漂亮的开场白，而是**有多少连接被真人接管**。"
4. **只留下匹配记录或聊天记录**（00:22:17）—— 原话直接判定："我们认为这是没有价值的。"
5. **AI 喧宾夺主**（00:18:45）—— 小火人的定位原话是"辅助你们俩的真实聊天，而非喧宾夺主"。
6. **人格测试 / MBTI / 高匹配度分数作为连接理由**。莲花山案例（00:06:16）原话强调的是反面：
   > "我们并未要求用户预先进行人格测试或提供 MBTI 类型，再由算法判定匹配度高达 99%。本质上，这是一个关于内容、城市与恰当时机的时间窗口，为这群陌生人提供了自然开口的理由。"
   >
   > **推断**（非原话）：demo 界面上出现"契合度 92%"这类不可解释的分数，大概率是负分项。

**这份清单直接决定 demo 界面上该显示什么数字。** 显示"AI 生成了 N 条开场白"是踩雷；显示"N 组真人接管 / 真实回应 / 一起完成了什么"是踩点。

## 8. 赛题内部的张力与未定义空间

这一节是本文的核心。以下是赛题自身没有解决、因而构成机会或陷阱的地方。

### T1 · 两位出题人的重心不在同一段关系上 ⚠️ 最重要

- 尤米的主场是**已有关系的持续经营**（火花 / 小火人 / 2+1），他反复强调"关系资产"。
- 说话人2 的痛点表述是**陌生同学 → 同伴**（00:25:19："大家缺的是如何把身边的陌生同学真正变成自己的同伴"）。
- 而尤米自己明说这两条路径"问题或解法完全不同"。

**含义**：作品必须**显式选边并说清楚为什么**。含糊两头会在第一问上同时失分。

**未被命名的第三个位置**：两人都描述了、但都没有给它起名字的一段关系 ——
**同校、有共同身份、在同一个群里见过、但从未真正说过话的"半熟人"**。
说话人2 描述的"一次性功能性群"（新生群、课程群、比赛群）里躺着的正是这批人。这段关系既不是纯陌生人（有校园身份和共同上下文可用，天然规避了陌生人社交的信任与安全成本），也不是已有关系（没有互动史，正是尤米说的"关系尚未开始"）。**这可能是赛题最甜的落点，且它在转写里是一个空位。**

### T2 · 禁止做校园墙，但切入点 B 就是校园墙在解决的问题

赛题一边禁止校园墙，一边把"需求找人"列为核心切口，并承认现有解法就是校园墙和各平台发帖。

**含义**：差异化不能发生在"信息发布"层，必须发生在校园墙做不到的四件事上——而这四件事恰好就是说话人2 亲口点出的四个断点（第 5 节 B）：需求翻译、定向分发、信任前置、成局后编排。**赛题实际上是在要求"把校园墙的失败率降下来"，同时禁止你复制校园墙的形态。**

### T3 · AI 越有用 ↔ AI 越容易变成"替人社交"

官方红线是"少替人说一句"。而官方自己在多闪做的 agent-to-agent 预热（崽崽），恰恰是"多替人说"。尤米自己给这个方向打了风险标签（00:09:45）。

**含义**：做 a2a 方向不是禁区，但必须正面回答**"AI 在哪一刻必须停手并把控制权交还给人"**，并且这个停手机制要在 demo 里被看见。不做 a2a，则可以把"我们刻意不让 AI 替你说话"本身作为差异化立场。

### T4 · 48 小时只能切一段 ↔ 第四问要求展示链路尾部的关系资产

说话人2 允许只切一个点（00:32:11），但尤米的第四问要求你展示"AI 退出后留下了什么"，这天然要求走到链路尾部。

**含义**：正确形状不是"做完整链路的前 1/3"，而是**一条极窄但贯通头尾的纵切**——需求类型可以窄到只有一种，但必须从"被看见"一路演到"留下了什么、下一次为什么还会用"。中段（真实的多人协作过程）在 demo 里允许用可信的时间跳跃或模拟带过，因为官方已经明说不指望真实后端和真实用户。

### T5 · 游园会是被低估的资产 —— "论证"可以升级成"证据"

现场问答里，"如何证明有效"得到的官方答案是"论证 + 可体验 demo"。但转写里还有一条信息没有被追问：**赛后有游园会，届时会有大量真实同龄用户在同一物理场地体验作品**。

**含义（推断）**：这是一个把"我们论证它会有效"变成"它在游园会现场真的连上了 N 组人"的机会。如果作品的核心机制能在几百人同处一地的场合真实跑一次，它拿到的就是同场唯一的真实效果证据。这一点转写里无人说破，但由"游园会"+"必须可体验"两句话直接可推。

### T6 · "不需要跟抖音强关联"是技术口径，不是心智口径

字面上不需要接抖音、不需要跟小火人有关。但两位评委的评价语言完全来自抖音的关系模型（被看见/开口/共同行动/共同记忆、2+1、关系资产、human in the loop）。

**含义**：不要接抖音 API，但**产品叙事应当能被翻译进他们的词汇表**。用他们的四问来组织讲述，是零成本的对齐。

### T7 · 社交介质的下一形态：从"更好的 profile"转向"可回应的意图"

两位讲者独立给出了同一条线索：
- 说话人2 的介质演化史停在 skill，并追问下一步是什么（00:28:17）。
- 尤米给出了具体的翻译例子（00:13:34）：
  > "仅说'我喜欢摄影'信息量不足，而翻译为'我这个周末想拍毕业短片，缺一个会调色的人'这样更具体的需求，反而更容易促成真实连接。"
- 尤米随后总结（00:14:14）："AI 其实是可以把一个**模糊的兴趣**翻译成**可回应的意图**，然后再去找到双方真正重叠的 context。"

**含义**：切入点 A 的陷阱是做成"又一张更花哨的 AI 名片"。赛题内部给出的答案方向是——**下一代社交介质可能不是更丰富的静态画像，而是带时效的、可被回应的意图**。做静态 profile 是把赛题往回做。

### T8 · "节点是关系而不是用户"是官方已验证但未解决的方向

现场问答（00:38:32–00:39:25）里有一段密度极高的交换：

- 问："我们这个世界的节点不是用户，而是把关系放在里面是吗？" 答："**对，是的。**"
- 尤米自陈："这可能就是这个过程中会有一点点 **tricky** 的部分，就是小火人的这个载体其实有点像我们俩养的宠物。"
- 问："它是否支持 3+1 或 4+1？" 答："**目前没有，它是一个 2+1 的形式。**"
- 问："我有五个朋友，需要跟这五个朋友每个人都养一个小火人？" 答："**对，是的。**"

**含义**：官方在自己的旗舰产品上，公开承认了三件事：(1) 把节点从用户换成关系是对的方向；(2) 这么做很 tricky；(3) 它目前卡在 2 人、且随好友数线性膨胀。**校园里的组队、社团、项目天然是 N 人的**，所以"N 人共同拥有一个东西"是官方点头认可方向、又公开承认自己没做到的空白地带。

### T9 · 被点名却无人给解法的两个断点

赛题把这两个断点说得很具体，但两位讲者都没有提出解法——这是明确的开放题面：

1. **信任断点**："有些陌生人还觉得你可能是个骗子，他不知道怎么去进一步地联系你。"
   校园的半封闭身份恰好是天然解法材料——说话人2 自己说了"你们本身就被赋予了一个共同的身份"。
2. **一次性群的死亡**："这些群更多起到了功能性的作用，可能事情结束之后，这个群也就沉寂了。"
   这是校园最高频、最普遍、最易验证的社交浪费。任何能把"事结束后群沉寂"转化为"事结束后留下可复用的东西"的机制，同时命中切入点 C 和尤米的第四问。

### T10 · 内容作为低压力的第一层表达

尤米对抖音社交起点的解释（00:04:16）值得单独拎出来，因为它是一个可迁移的机制而不是抖音特有的：

> "直接做自我介绍的心理门槛可能很高，但如果让我转发一条视频并说'这不就是你吗？'……压力就小很多。**内容其实是替人完成了第一层表达，但关系仍由人自己完成。**"

莲花山案例（00:05:47）是这个机制的完整样本：内容共鸣 → 同城识别 → 评论区有人先开口 → 拉群 → 线下约定。尤米对它的产品化提问是：
> "当共鸣产生时，我们如何**识别这种信号**，并降低从'我也想去'到'我们一起去'的**成本**。"

**含义**：这是赛题给出的、经过实战验证的降低开口压力的路径——用一个外部的共同对象（内容/事/物）承担第一层表达，人只需要做"回应"这个低成本动作。校园里的等价物是什么，是一个开放且高价值的问题。

## 9. 官方参照系：火花 / 小火人 / 崽崽

这三个是评委的"母语"。理解它们，是为了理解评委的判断习惯，不是为了模仿。

### 9.1 火花

关系持续互动后产生的**关系标记**，作用是"让原本无感知的关系变得**可感、可见**"（00:15:09）。
外部核实的机制：与好友连续聊天 3 天点亮；发消息、发图累积"火星"。（来源为民间教程，非官方文档，可信度中等）

### 9.2 小火人 —— 2+1 模型

官方定义（00:15:39）：**不是 AI 助手，不是聊天机器人，是"因两人双人羁绊而产生的小精灵"。**

2+1 的含义（00:16:26）：2 个真人 + 1 个小火人。
> "我们不希望它只是往双人聊天里硬塞第三个聊天对象，而是**为这段关系增加一个共同界面**，我们两个人始终才是这个关系的主体。"

三个关键词（00:16:54）：
- **共同拥有** —— 不属于我们俩的任何一方，而属于这段关系
- **共同投入** —— 通过任务、互动、装扮、小仪式让它成长
- **共同记住** —— 信息流里易流失的聊天片段与经历沉淀为关系记忆

三段式成长框架（00:17:26–00:19:47），这是一个可复用的产品结构：

| | 内容 | 关键判断（原话） |
|---|---|---|
| 好看的皮囊 | 形象装扮、成长、仪式感 | "一个形象之所以有价值，并非因为它可爱，而是因为它**由我们两人共同装扮而成**" |
| 有趣的灵魂 | 对话风格、共同话题、关系记忆、理解上下文 | "逐渐懂得你们并非孤立的用户，而是拥有共同经历的伙伴" |
| 灵活的手脚 | 升级为 **agent 架构**，按需调度工具（生成图片、喂食、穿搭），开放自定义对话技能 | "手脚则希望它能与两人**一起做事**" |

**精灵世界**（00:20:25）：带着自己的小火人去世界游玩，与其他小火人产生真实连接。群聊场景"可能会支持大家把自己的小火人放到一个空间下面，让他们产生互动"（00:38:20，即"在设计中"，非已上线）。

### 9.3 多闪崽崽 —— 陌生人路径的官方实验

转写描述（00:11:33–00:12:56）：
- 位于**多闪 APP**，是抖音在**陌生人社交**场景的探索
- "某某用户的崽崽" = 基于用户照片生成的虚拟形象，代表外貌
- 结合抖音内聊天记录、公开作品等**授权内容**，构成对外人格画像
- 崽崽之间可以互相交流（a2a），沉淀有价值的内容推送给用户
- 用户也可以直接与对方的崽崽交流，以了解对方本人

⚠️ **与外部报道存在出入**：公开报道（钛媒体/36kr，2026-05）对多闪仔仔的描述侧重"上传照片生成 3D 卡通形象 + 多闪世界 + 明星虚拟分身"，并明确说多闪的产品设计"都聚焦已有关系……AI 的作用不是创造新连接，而是激活和加深已有关系"。
可能的解释：讲者描述的 a2a 陌生人预热能力属于较新或小流量能力，或属于产品意图而非全量上线形态。**引用时应表述为"抖音在多闪上的探索方向"，不宜表述为"已上线的成熟能力"。**

## 12. 建议向主办方澄清的问题

转写里没有覆盖、但会影响施工决策的：

1. **游园会的具体形态**：多少人、多长时间、是否允许现场收集真实用户数据？（直接决定 T5 那个机会能否兑现）
2. **评审时长与形式**：几分钟路演 + 几分钟体验？评委是自己上手还是看演示？
3. **是否允许使用真实同学作为 demo 参与者**（涉及隐私与现场信息收集边界）
4. **是否提供模型 API / 算力额度**，以及是否限定必须使用某家模型
5. **"方案部分"的具体交付物**：是 PPT、文档，还是路演即可？有无模板与页数限制？
6. **是否有数据合规要求**（校园身份、人脸、位置这类敏感信息在 demo 中的使用红线）
